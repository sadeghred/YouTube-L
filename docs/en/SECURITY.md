# Security & Privacy

The production system handles sensitive authentication state.

## Never Publish

- Google username/password
- Telegram bot token
- Telegram API credentials
- Live browser cookies
- Chrome profile files
- Telegram session files
- SSH keys
- Production databases or user data
- Environment files containing secrets
- Deployable private source archives

## Public Documentation

Safe public material includes architecture, feature descriptions, sanitized diagrams/screenshots, project status, and roadmap. Production credentials, infrastructure access details, session material, and private deployable implementation remain private.
