# امنیت و حریم خصوصی

Production این پروژه با وضعیت حساس Authentication کار می‌کند.

## هرگز منتشر نشود

- Username/Password حساب Google
- Telegram Bot Token
- Telegram API Credential
- Cookie واقعی Browser
- فایل‌های Chrome Profile
- Telegram Session
- SSH Key
- Database Production یا اطلاعات کاربران
- Environment شامل Secret
- آرشیو سورس خصوصی قابل Deploy

## مستندات عمومی

معماری، قابلیت‌ها، Diagram/Screenshot سانسورشده، وضعیت پروژه و Roadmap مناسب انتشار هستند. Credential، دسترسی Infrastructure، Session Production و Implementation خصوصی قابل Deploy باید خصوصی بمانند.
